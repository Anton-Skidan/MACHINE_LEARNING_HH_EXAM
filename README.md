## Цель проекта

Исследовать структуру базы резюме HeadHunter, преобразовать текстовые признаки, изучить зависимости между характеристиками соискателей и желаемой зарплатой, затем очистить данные от дубликатов, пропусков и выбросов.

Основной датасет — `dst-3.0\\\\\\\\\\\\\\\_16\\\\\\\\\\\\\\\_1\\\\\\\\\\\\\\\_hh\\\\\\\\\\\\\\\_database.csv` (или ZIP с этим CSV). В нём **44 744 резюме и 12 столбцов**. При чтении CSV используется разделитель `;`.

Большой исходный файл не включён в архив проекта и не должен размещаться в GitHub. Для этого в `.gitignore` исключён каталог `data/`, а также файлы `\\\\\\\\\\\\\\\*.csv` и `\\\\\\\\\\\\\\\*.zip`.

### Курсы валют для задания 3.6

Для полного воспроизведения зарплатных расчётов используется учебный CSV исторических курсов со столбцами:

* `currency` — ISO-код валюты;
* `date` — дата курса;
* `proportion` — число единиц валюты, к которым относится курс;
* `close` — курс в рублях для указанной пропорции.

Пропорции валют приведены в условии задания:

|Валюта в резюме|ISO|Пропорция|
|-|-|-:|
|грн|UAH|10|
|USD|USD|1|
|EUR|EUR|1|
|белруб|BYN|1|
|KGS|KGS|10|
|сум|UZS|10 000|
|AZN|AZN|1|
|KZT|KZT|100|

Для зарплат в рублях курс равен единице. Для остальных валют применяется формула:

`ЗП (руб) = сумма × close / proportion`

Курс определяется **на дату обновления резюме**. Указанные выше пропорции сами по себе не заменяют таблицу ежедневных значений `close`.

## Как запустить

1. Распаковать ZIP проекта и открыть терминал в каталоге с ноутбуком.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Создать папку `data/` рядом с ноутбуком и поместить в неё `dst-3.0\\\\\\\\\\\\\\\_16\\\\\\\\\\\\\\\_1\\\\\\\\\\\\\\\_hh\\\\\\\\\\\\\\\_database.zip` или `dst-3.0\\\\\\\\\\\\\\\_16\\\\\\\\\\\\\\\_1\\\\\\\\\\\\\\\_hh\\\\\\\\\\\\\\\_database.csv`.
4. Для выполнения полного анализа зарплат сохранить таблицу курсов как `data/ExchangeRates.csv` **либо** указать прямую ссылку на CSV в переменной `RATES\\\\\\\\\\\\\\\_SOURCE` в ячейке **3.6**.
5. Открыть `HH\\\\\\\\\\\\\\\_PYTHON\\\\\\\\\\\\\\\_EXAM\\\\\\\\\\\\\\\_SKIDAN\\\\\\\\\\\\\\\_A\\\\\\\\\\\\\\\_A.ipynb` в Jupyter Notebook и выполнить **Restart \& Run All**.

## Этапы работы

1. **Исследование структуры данных:** размер таблицы, типы данных, пропуски и описательные статистики.
2. **Преобразование данных:** образование, пол, возраст, опыт работы, город, готовность к переездам и командировкам, занятость, график и конвертация зарплат.
3. **Разведывательный анализ:** распределения и зависимости, включая два дополнительных графика.
4. **Очистка данных:** дубликаты, заполнение пропусков, очистка зарплат, аномальный стаж и выбросы возраста.

Графики снабжены заголовками, подписями осей и короткими выводами в Markdown. Используются библиотеки `pandas`, `numpy`, `matplotlib` и `seaborn`.
